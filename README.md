## 🌟 Key Features

- **Cyber-Executive UI Design:** Custom CSS design system utilizing CSS variables for theme consistency, neon glows, and glassmorphism backdrops.
- **Responsive & Mobile-First:** Fluid typography (`clamp()`) and adaptive grid architecture for seamless viewing across mobile, tablet, desktop, and ultra-wide screens.
- **Interactive Dynamic UI:**
  - Auto-scrolling infinite capability matrix / marquee.
  - IntersectionObserver-driven viewport animations and active scroll tracking.
  - Interactive animated count-up metrics for delivered work.
  - 1-Click Clipboard Email copy with real-time feedback toast.
- **SEO & Accessibility Focused:** Semantic HTML5 landmarks, Schema.org Person JSON-LD microdata, OpenGraph tags, and print stylesheets.
